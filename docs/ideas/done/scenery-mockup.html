Scenery for the run

Six looks for the empty sky and roadside, drawn live with the game's own camera (low, 8° down, 34° view), track and colours. The blue crowd is a stand-in for the army. Pick one, or mix parts.

All of these are built from boxes, cones and spheres in code, like the figures: no downloaded art. Everything scrolls past at run speed and fades into the same haze, so nothing changes gameplay or the camera. Phone view shows how little of the roadside fits on a narrow screen, which is why the sky matters there.
