# Fold the round skills into one project flow

Status: idea, 2026-11-15. Not confirmed.

An sdd round runs through five skills: `triage` → `interview-me` → `spec-driven-development` → `planning-and-task-breakdown` → orchestrate (AGENTS.md), plus the review pages (`docs/review-pages.md`). Three of those skills are generic imports with a lot of text this project doesn't use (capability maps, PRD templates, `docs/intent/` handoffs).

Idea: audit what each step is used for here and fold them into one project-specific "round" flow (interview → idea doc → spec → tasks → spec page → orchestrate → checkpoint page), keeping `triage` as the router.
